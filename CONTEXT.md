# Context

## Auth module setup

The module setup that resolves auth config, mode flags, provider selection, runtime config, generated aliases, and route-rule metadata before runtime registration.

## Auth config discovery

The layer-aware lookup that determines which server and client auth config files are effective for a Nuxt project.

## Schema generation

The build-time generation of Better Auth database schema artifacts, especially for NuxtHub-backed database setups.

## Type augmentation

The generated declaration surface that infers auth user, session, endpoint, and client types from the effective auth config.
